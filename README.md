# API Dashboard Project

A responsive web dashboard that fetches and displays live data from public APIs.

## Live Demo
https://effortless-sopapillas-e049e8.netlify.app

## Features
- Live weather data by city name
- Latest tech news headlines
- Error handling and loading states
- Responsive design

## APIs Used
- Open-Meteo Weather API (free, no key needed)
- Hacker News API (free, no key needed)

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API
- Async/Await

## How to Run
1. Clone this repository
2. Open index.html in your browser
3. Search any city for weather
4. Click Load News for headlines
